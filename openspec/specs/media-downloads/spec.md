# Загрузка медиа

## Purpose

Определяет опциональное обнаружение, учёт и устойчивую загрузку файлов, упомянутых в содержимом Telegram-сообщений.

## Requirements

### Requirement: Загрузка включается явно

Система SHALL по умолчанию сохранять описания медиа без обязательной загрузки файлов и SHALL начинать загрузку только при включённом флаге.

#### Scenario: Флаг загрузки выключен

- **GIVEN** загрузка медиа не включена
- **WHEN** приходит сообщение с медиа
- **THEN** описание содержимого и обнаруженные состояния файлов сохраняются
- **AND** collector не отправляет запрос на загрузку из-за этого сообщения

#### Scenario: Флаг загрузки включён

- **GIVEN** загрузка медиа включена
- **AND** сессия Telegram готова
- **WHEN** обнаружен доступный незавершённый файл
- **THEN** collector ставит файл в устойчивую очередь и запрашивает его загрузку

### Requirement: Рекурсивное обнаружение файлов

Система SHALL обнаруживать уникальные файловые объекты во вложенной структуре нового или изменённого содержимого сообщения.

#### Scenario: Содержимое включает основной файл и миниатюру

- **GIVEN** объект содержимого содержит несколько вложенных файловых объектов
- **WHEN** система исследует содержимое
- **THEN** каждый уникальный положительный идентификатор файла регистрируется один раз

### Requirement: Реестр состояний файлов

Система SHALL сохранять последнее доступное состояние каждого обнаруженного файла независимо от режима автоматической загрузки.

#### Scenario: Файл обнаружен впервые

- **GIVEN** содержимое сообщения ссылается на неизвестный файл
- **WHEN** сообщение нормализуется
- **THEN** сохраняются идентификатор, размеры, доступность, прогресс, удалённое описание и полный объект файла
- **AND** фиксируется время первого наблюдения

#### Scenario: Получено обновление прогресса

- **GIVEN** файл уже зарегистрирован
- **WHEN** Telegram сообщает новое состояние файла
- **THEN** реестр обновляет прогресс, локальный путь и признаки загрузки
- **AND** время первого наблюдения сохраняется

#### Scenario: Загрузка завершена

- **GIVEN** Telegram сообщил о завершённой загрузке
- **WHEN** состояние файла обработано
- **THEN** реестр содержит локальный путь и время завершения

### Requirement: Восстановление очереди после запуска

Система SHALL при готовности авторизованной сессии повторно обнаруживать файлы в сохранённых сообщениях и запрашивать доступные незавершённые загрузки.

#### Scenario: Collector перезапущен во время загрузки

- **GIVEN** загрузка медиа включена
- **AND** в сохранённых сообщениях есть доступный незавершённый файл
- **WHEN** после перезапуска сессия Telegram становится готовой
- **THEN** файл снова попадает в очередь запросов
- **AND** завершённые файлы повторно не запрашиваются

### Requirement: Приоритет загрузки

Система SHALL передавать каждому автоматическому запросу настроенный допустимый приоритет загрузки.

#### Scenario: Настроен приоритет

- **GIVEN** оператор задал допустимый приоритет
- **WHEN** collector запрашивает файл
- **THEN** запрос содержит заданный приоритет

#### Scenario: Приоритет вне допустимого диапазона

- **GIVEN** оператор задал недопустимый приоритет
- **WHEN** collector загружает конфигурацию
- **THEN** запуск завершается ошибкой валидации вместо отправки некорректного запроса

### Requirement: Постоянное хранение загруженных файлов

Система SHALL размещать каталог файлов Telegram в постоянном хранилище, переживающем замену и перезапуск контейнера.

#### Scenario: Контейнер collector пересоздан

- **GIVEN** файл был успешно загружен в постоянный каталог
- **WHEN** контейнер collector пересоздаётся без удаления постоянного хранилища
- **THEN** загруженный файл и состояние сессии остаются доступными

### Requirement: Изоляция ошибки загрузки

Система SHALL регистрировать ошибку отдельного запроса медиа и SHALL NOT завершать основной цикл collector из-за неё.

#### Scenario: Telegram отклонил загрузку файла

- **GIVEN** был отправлен запрос автоматической загрузки
- **WHEN** Telegram возвращает ошибку этого запроса
- **THEN** журнал содержит идентификатор файла, код и сообщение ошибки
- **AND** collector продолжает обработку следующих событий
