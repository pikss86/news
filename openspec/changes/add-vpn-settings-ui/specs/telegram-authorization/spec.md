## MODIFIED Requirements

### Requirement: Конфигурация учётных данных

Система SHALL получать идентификатор приложения, секрет приложения, номер телефона и ключ локальной базы из действующей подтверждённой конфигурации; постоянная конфигурация панели SHALL иметь приоритет над bootstrap/fallback-окружением.

#### Scenario: Запуск с настроенными значениями

- **GIVEN** существует полная валидная ревизия с параметрами Telegram
- **WHEN** collector запускается
- **THEN** параметры действующей ревизии передаются подсистеме Telegram
- **AND** реальные значения не требуется хранить в репозитории

#### Scenario: Постоянная конфигурация ещё не создана

- **GIVEN** отсутствует сохранённая ревизия настроек
- **WHEN** доступны валидные Telegram-параметры bootstrap/fallback-окружения
- **THEN** collector может использовать их для совместимого запуска

#### Scenario: Отсутствует обязательное значение

- **GIVEN** обязательный параметр Telegram отсутствует или пуст во всех разрешённых источниках
- **WHEN** сервис загружает конфигурацию
- **THEN** collector не запускается
- **AND** панель сообщает о неполной конфигурации
- **AND** система не имитирует успешное подключение
