## MODIFIED Requirements

### Requirement: Загрузка включается явно

Система SHALL по умолчанию сохранять описания медиа без обязательной загрузки файлов и SHALL начинать загрузку только после включения настройки в действующей конфигурации.

#### Scenario: Флаг загрузки выключен

- **GIVEN** действующая ревизия отключает загрузку медиа
- **WHEN** приходит сообщение с медиа
- **THEN** описание содержимого и обнаруженные состояния файлов сохраняются
- **AND** collector не отправляет запрос на загрузку из-за этого сообщения

#### Scenario: Флаг загрузки включён

- **GIVEN** действующая ревизия включает загрузку медиа
- **AND** сессия Telegram готова
- **WHEN** обнаружен доступный незавершённый файл
- **THEN** collector ставит файл в устойчивую очередь и запрашивает его загрузку

### Requirement: Приоритет загрузки

Система SHALL валидировать приоритет на странице настройки и SHALL передавать каждому автоматическому запросу приоритет действующей ревизии.

#### Scenario: Настроен приоритет

- **GIVEN** оператор сохранил допустимый приоритет
- **WHEN** collector запрашивает файл после применения ревизии
- **THEN** запрос содержит заданный приоритет

#### Scenario: Приоритет вне допустимого диапазона

- **GIVEN** оператор ввёл недопустимый приоритет
- **WHEN** форма отправлена
- **THEN** новая ревизия не сохраняется
- **AND** страница показывает допустимый диапазон
